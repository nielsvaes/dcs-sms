## What this branch builds

A **DCS-SMS → Hotkeys** ME tool window to bind keyboard shortcuts to native Mission-Editor actions (Multi Select, object-add tools, panel toggles). Single-letter defaults for keyless actions; native actions keep their ED keys; Unreal-style reset-to-default (`↩`); bindings persisted across sessions in `Saved Games\DCS\dcs-sms\me_hotkeys.lua`.

Architecture: four pure unit-tested layers + a dxgui window + a facade.

| File (all under `tools/me-mod/lua/dcs_sms_me/`) | Role |
|---|---|
| `me_hotkey_actions.lua` | Action registry: id/label/category/default_key/ed_key + lazy `invoke` thunks + `ED_CONFLICTS` map + `normalize_key`. |
| `me_hotkey_config.lua` | Override-delta persistence (`me_hotkeys.lua` file) + pure `serialize`/`deserialize` + `BACKEND_MODE` (default `'perkey'`). |
| `me_hotkey_engine.lua` | Pure keymap diff/state engine (`bind/unbind/reset/reset_all/current_key/is_modified/rows/apply`) over an injected backend. |
| `me_hotkey_backend.lua` | dxgui backends: `perkey` (toolbar-window `addHotKeyCallback`) + `global` (`Gui.AddKeyboardCallback` chokepoint) + pure `match_chord`. |
| `me_hotkey_window.lua` | The window: `sms_window` + 2-col Grid + capture overlay + reset affordances. |
| `me_hotkeys.lua` | Facade singleton: builds engine, `install()` on bootstrap, `persist()`, `toggle_window()`. |
| `init.lua`, `menu.lua` | Wiring: bootstrap install + "Hotkeys" menu entry. |

Tests: `tools/me-mod/test/test_hotkey_{actions,config,engine,backend}.lua` (52 assertions, all pass; registered in `run-tests.ps1`).

## Known caveat

**dev-reload double-attach:** after `dcs-sms dev-reload`, bindings may fire twice until a full DCS restart (the `perkey` backend can't recover lost callback refs across hot-reload). Cold ME start is clean. Documented in spec §9a.4.
