# `dcs-sms set-saved-games`

[← CLI reference index](README.md)

pin the DCS Saved Games folder in config (run bare to list the folders found)

## Usage

```
dcs-sms set-saved-games [flags]
```

## Examples

```
dcs-sms set-saved-games
```

```
dcs-sms set-saved-games "C:\Users\you\Saved Games\DCS.openbeta"
```
